# Rashidi Umrah Tours & Travels — sample website

Mobile-friendly static website concept with sample upcoming departures, city/month/package filters, package details, itinerary, ziyarat, facilities, Hajj enquiry and FAQs.

## Deploy on Vercel

Import this repository. Choose **Other** for the Framework Preset. Leave Build Command and Output Directory unset. The root `index.html` is the website; no dependencies or environment variables are required.

## Demo scope

All prices, dates and package details are illustrative. There is no live inventory, payment collection or backend. The enquiry form displays a preview locally and does not transmit or store information.

Before a commercial launch, add verified operator identity, contact information, package arrangements, hotel distances, policies and a real enquiry destination. No Hajj authorization or permit availability is claimed.
